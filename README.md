# 🚀 SkillUp AI

SkillUp AI is an AI-powered learning and career development platform designed to help students learn skills, explore career paths, practice quizzes, access learning resources, and prepare for interviews.

## ✨ Features

- 📚 Personalized Learning & Career Roadmaps
- 📝 Skill-based Quizzes
- 🎥 Learning Resources
- 🤖 AI Learning Assistant
- 🎤 AI Mock Interview
- 👤 User Profile & Progress Tracking
- 🔐 Secure Authentication
